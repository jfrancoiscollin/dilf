# MTDP — Scan depth-16 sensitivity on 120 frozen targets

The [preregistered study](../../SCAN_DEPTH16_SENSITIVITY_PROTOCOL_2026-11-12.md)
rescored 2,067 legal successors across three independent events. All
120 targets and their PC Blues source matches were retained. Scan 3.1
used the pinned binary, one thread, a cold transposition table per
evaluation, no book and no tablebases. Only successor depth changed.

## Reevaluating the archived Jass moves

All 1,080 archived arm results were reevaluated at both depths. Jass
searches were held fixed. At the primary budget of 200,000 nodes the
table reports mean paired regret differences in men, weighting each
target game equally. Negative values favor transfer. Parentheses give
the depth-16 95% bootstrap interval (10,000 replicates, seed 20261112).
Each distinct FEN belongs to its first target game in lexicographic
order. The combined interval resamples within each event.

At 200,000 nodes, 3/120 paired differences against canonical and 5/120
against native went from positive to negative or the reverse. The first
two events used persistent root ordering and the third used
first-iteration ordering. In the third event the identical Jass choices
necessarily yield identical regret under either reference. These
selected, sparse cohorts still provide no consistent gain in move
quality for the transfer arms. The pooled figures describe these
cohorts and do not estimate a common effect for both search variants.

## Reproduction

Run from the DILF repository with draught-master at
`0e5189fbb251bf5eaf2e613d0f878bb17c740311` and Scan at
`7aae17e7b7bfc47744601afb1ee7655e18983ce5`. The
[provenance manifest](provenance.json) records SHA-256 of each original
archive and uncompressed payload, along with Scan's binary, evaluation
file and configuration. The pinned build receipts independently tie
each depth-12 reference to its frozen cohort. Compare the fresh outputs
to the archived depth-16 references.

```sh
export PYTHONPATH="$PWD:$DRAUGHT_MASTER_ROOT"
study=research/mtdp/jass_benchmark/scan-depth16
tmpdir=$(mktemp -d)
for event in Z3s40c6H iPQl7g7q 0gB7ETSW; do
  manifest=$(jq -r --arg event "$event" '.cohorts[$event].inputs.manifest.path' "$study/provenance.json")
  case "$manifest" in
    *.gz) gzip -dc "$manifest" > "$tmpdir/manifest.json" ;;
    *) cp "$manifest" "$tmpdir/manifest.json" ;;
  esac
  python -m research.mtdp.jass_scan_reference --depth 16 \
    --scan "$SCAN_ROOT/scan_linux" --manifest "$tmpdir/manifest.json" \
    --output "$tmpdir/$event.json" || exit
  gzip -dc "$study/$event-reference16.json.gz" | cmp - "$tmpdir/$event.json" || exit
done
python -m research.mtdp.jass_benchmark.depth_sensitivity \
  --provenance "$study/provenance.json" --output "$tmpdir/comparison.json"
gzip -dc "$study/comparison.json.gz" | cmp - "$tmpdir/comparison.json"
```

The comparison verifies the complete action set for each scored FEN at
both depths and the exact Jass receipt grid (every target, budget and
arm). At depth 12 it independently verifies the chosen action's score
and regret against the archived receipt. The comparison JSON contains
per-pair optima, coverage and costs, plus per-budget and per-arm
summaries, sign changes and game-clustered intervals. Categorical scores
are counted separately from ordinary score differences.

Two complete depth-16 scoring runs matched byte for byte for the 28-
and 17-target cohorts. The 75-target reference was scored once. For
all 22 cross-event instances of a shared source FEN, the independent
event runs agreed exactly at both depths. The analysis reproduced
byte for byte on a second run. The default scorer reproduced the
archived depth-12 reference for the 17-target cohort. All 86 MTDP and
643 DILF tests passed.
