# Offline top-three control on the three frozen tournaments

The [preregistered protocol](../OFFLINE_TOP3_CANONICAL_CONTROL_PROTOCOL_2026-11-12.md)
was executed on all 120 frozen targets at Scan depths 12 and 16. Each
list contained exactly three legal actions. One target had exactly
three legal actions, so both lists covered its complete action set.
The canonical control took the three smallest frozen Jass move keys in
bytewise order. Transfer ranked the paired PC Blues source actions
by Scan score at the matching depth, breaking ties by the same key.
Target scores were used only to evaluate the lists.

The two larger cohorts favored transfer at both depths. The smallest
cohort changed direction. The source scores tied at the third-place
cutoff in 40 positions at depth 12 and 41 at depth 16. At depth 12
the earlier sensitivity audit reported 83/120 using numerical action
tuple ordering for ties. The preregistered bytewise Jass key ordering
in this study yields 81/120.

The pooled paired median delta is zero at both depths.
At each depth, one transfer list and eight canonical lists cost at
least 0.50 men. The largest costs at depth 16 were 1.28 and 1.42 men,
respectively. The data archive records each candidate list, ties and
overlap. The two candidate sets were identical on 6/120 targets at
each depth.

This control estimates shortlist quality when an oracle picks the best
available move using the target scores. A playing engine must still
choose a move under its own budget. The two references use the same
selected tournaments and depth-matched source rankings.

## Reproduction

Run from the repository root. The script verifies the archived
manifests and references against their SHA-256 records and checks
complete source and target action catalogues.

```sh
study=research/mtdp/jass_benchmark
python -m research.mtdp.jass_benchmark.offline_top3_control \
  --provenance "$study/scan-depth16/provenance.json" \
  --output /tmp/mtdp-offline-top3.json
gzip -dc "$study/offline-top3-control/comparison.json.gz" | cmp - /tmp/mtdp-offline-top3.json
```

Two runs with distinct Python hash seeds produced byte-identical output,
SHA-256 `01a60a4deb32766f36c029161a9481f84bbb6def006ac86e9874771cddbec776`.
92 MTDP tests and 643 DILF tests passed. The optional live Jass
catalogue test was skipped because the binary was absent. This
analysis used the archived one-to-one move mappings.
