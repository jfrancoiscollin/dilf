# Scan depth sensitivity of the Jass move disagreements

This check uses the five targets where LCB and L chose different
moves at 50,000 Jass nodes. It keeps the archived Jass choices
and depth-12 source ranks fixed and rescores all 48 legal target
successors using the same Scan 3.1 build at depth 18.

| Arena | LCB move | L move | Regret difference at depth 16 | Regret difference at depth 18 |
| --- | --- | --- | ---: | ---: |
| MtDQWBNR | 34-29 | 34-30 | +4 | +4 |
| CARZrQpl | 13-19 | 14-19 | +11 | +12 |
| CARZrQpl | 14-19 | 20-24 | −3 | −4 |
| CARZrQpl | 14-19 | 20-24 | −6 | −10 |
| CARZrQpl | 33-29 | 32-28 | +10 | +10 |

Differences are LCB minus L, in centimen. All five signs agree
across depths and all scores stay ordinary. On one target the LCB
move becomes a Scan optimum at depth 18. Across the five targets,
LCB finds one optimum at depth 16 and two at depth 18. L finds one
at both depths. These counts apply to the selected disagreement
subset. The full-cohort estimate uses the registered depth-16
reference. The [summary](summary.json) identifies each position
and records both arms' individual regret and optimum status.

## Reproduction

From the DILF root, use the pinned Scan and adapter from the
[scoring handoff](../STATUS.md#scoring-handoff).

```bash
rep=research/mtdp/jass_benchmark/spatial-jass/replication
export PYTHONPATH="$PWD:$DRAUGHT_MASTER_ROOT"
args=()
for event in uG0fGZzB l45uk39x GYEtKzUg MtDQWBNR CARZrQpl; do
  args+=(--arena "$rep/$event")
done
python -m research.mtdp.jass_benchmark.spatial_depth_check \
  "${args[@]}" --manifest /tmp/mtdp-spatial-depth18-manifest.json
cmp "$rep/depth18/manifest.json" /tmp/mtdp-spatial-depth18-manifest.json
python -m research.mtdp.jass_scan_reference --role target --depth 18 \
  --manifest "$rep/depth18/manifest.json" --scan "$SCAN_ROOT/scan_linux" \
  --output /tmp/mtdp-spatial-depth18-target.json
cmp "$rep/depth18/target.json" /tmp/mtdp-spatial-depth18-target.json
python -m research.mtdp.jass_benchmark.spatial_depth_check "${args[@]}" \
  --manifest "$rep/depth18/manifest.json" --reference /tmp/mtdp-spatial-depth18-target.json \
  --output /tmp/mtdp-spatial-depth18-summary.json
cmp "$rep/depth18/summary.json" /tmp/mtdp-spatial-depth18-summary.json
```

The manifest and summary reproduced byte for byte under Python
hash seeds 7 and 61. The Scan score receipt also reproduced byte
for byte. Next, use the existing depth-12 and depth-16 references
to measure first-choice and top-three transfer on all 473 common
targets. Compare LCB with L on those same targets and on the 64
changed orders to see where initial candidate quality changes
before the fixed-budget search.
