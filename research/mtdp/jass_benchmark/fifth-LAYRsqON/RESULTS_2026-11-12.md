# Fifth held-out cohort — node-matched Jass results

The [preregistered benchmark](../FIFTH_COHORT_JASS_PROTOCOL_2026-11-12.md)
used the [20 frozen targets](FREEZE.md) from the 12 November 2026 5+0
standard arena. They make up 0.35% of the novel nonterminal quiet FENs.
Source rankings are from Scan 3.1 at successor depth 12. The target
reference scores all legal successors at depth 16.

## Candidate signal

The source and target optimum sets were disjoint on 12/20 pairs.
The first source move covered a target optimum on 7/20, and cost
at least half a man twice (maximum 2.41 men on Scan's scale).
The three transferred moves covered an optimum on 14/20 versus
9/20 for the three canonical moves. The paired difference was +25
percentage points (95% whole-game bootstrap interval 0 to +52.4).
The best available candidate cost 0.027 men on average with transfer
versus 0.095 with canonical ordering. The paired difference was
−0.068 (95% interval −0.182 to +0.018). These are offline outcomes
using the best available candidate under the target reference.

## Actual Jass choices

All 180 searches reached exactly their assigned node budgets. The
2,188 root attempts verify full first-iteration legal coverage and
native adaptive ordering after that iteration. Each ordered arm
applied the requested list once and each search used a fresh 1 MiB TT.
There were 20 ordinary-score pairs at each budget and no category
transitions.

| Jass nodes | Optima selected, transfer / canonical / native | Mean completed depth, transfer / canonical / native | Mean regret delta vs canonical (men) | Mean regret delta vs native (men) |
| ---: | --- | --- | ---: | ---: |
| 10,000 | 4 / 4 / 4 | 7.75 / 7.90 / 7.80 | 0.0000 | +0.0025 |
| 50,000 | 2 / 4 / 4 | 11.10 / 11.20 / 11.25 | +0.0160 | +0.0245 |
| 200,000 | 4 / 5 / 4 | 14.45 / 14.55 / 14.40 | +0.0105 | +0.0075 |

At the primary budget of 200,000 nodes, the paired transfer-minus-
canonical mean was **+0.0105 men** (95% whole-game bootstrap interval
−0.0063 to +0.0390; 14 owning games). The median was zero. The transfer
arm changed two of 20 moves compared with canonical, one better
and one worse. Against native, it changed four moves, two better
and two worse (95% interval −0.0218 to +0.0411 men). Excluding the
one multi-game target gave +0.0111 men versus canonical (95%
interval −0.0065 to +0.0427; 13 owning games).

This cohort does not establish a Jass move-quality gain at equal
nodes. The direction of the primary point estimate is unfavorable
to transfer, and the interval spans zero. It also does not establish
equivalence. Budgets cover Jass search, with source Scan ranking
computed offline. Wall times in the receipts are descriptive.

## Reproduction

Build the pinned Jass runner in the initial-only configuration and
verify its digest in [provenance.json](provenance.json). Start from
the published [frozen manifest](FREEZE.md) and the pinned Scan
configuration. Run from the repository root.

```sh
set -eu
export PYTHONPATH="$PWD:$DRAUGHT_MASTER_ROOT"
study=research/mtdp/jass_benchmark/fifth-LAYRsqON
tmpdir=$(mktemp -d)
gzip -dc "$study/cohort-manifest.json.gz" > "$tmpdir/manifest.json"
for role in source target; do
  case "$role" in source) depth=12 ;; target) depth=16 ;; esac
  python -m research.mtdp.jass_scan_reference --role "$role" --depth "$depth" \
    --manifest "$tmpdir/manifest.json" --scan "$SCAN_ROOT/scan_linux" \
    --output "$tmpdir/$role.json"
  gzip -dc "$study/$role-depth$depth.json.gz" | cmp - "$tmpdir/$role.json"
done
python -m research.mtdp.jass_benchmark.fourth_cohort_cross_depth \
  --provenance "$study/provenance.json" --source "$tmpdir/source.json" \
  --target "$tmpdir/target.json" --output "$tmpdir/offline.json"
gzip -dc "$study/offline.json.gz" | cmp - "$tmpdir/offline.json"
python -m research.mtdp.jass_benchmark.run --initial-only \
  --manifest "$tmpdir/manifest.json" --source-scan-reference "$tmpdir/source.json" \
  --scan-reference "$tmpdir/target.json" --runner "$JASS_BUILD/mtdp_jass_benchmark" \
  --output-dir "$tmpdir/jass"
gzip -dc "$study/root-order-traces.jsonl.gz" | cmp - "$tmpdir/jass/root-order-traces.jsonl"
gzip -dc "$study/paired-results.jsonl.gz" | jq -c 'del(.arms[].elapsed_us)' > "$tmpdir/archived.jsonl"
jq -c 'del(.arms[].elapsed_us)' "$tmpdir/jass/paired-results.jsonl" | cmp - "$tmpdir/archived.jsonl"
```

The C++ search requests contain FEN, budget and move keys. The source
ranking alone supplies the transfer keys; the target reference is
used in Python to score the returned move. The receipts record actual
node totals, root traces, moves, candidate prefixes and evaluation
categories. The summary includes paired target-game intervals and the
multi-game target sensitivity.

The references, offline comparison and root traces reproduced byte
for byte. The move receipts reproduced apart from wall time. The
historical third-cohort trace reproduced with the new option absent.
All 98 MTDP tests (including the live Jass catalogue), 643 DILF tests
and Jass unit tests passed.
