# Reference library — `docs/livres/`

This tree mirrors **section 5 of `CORPUS REFERENCE DAMES.pdf`** and is the
expected destination of every P1 PDF used to build the pedagogy framework's
fixtures, motif detectors and BookRAG index.

The PDFs are **not** committed to this repository. Fetch them with:

```bash
python scripts/fetch_corpus_p1.py            # full P1 (25 entries)
python scripts/fetch_corpus_p1.py --dry-run  # preview without HTTP calls
python scripts/fetch_corpus_p1.py --only dubois
```

Bonnard's *Revue Le Jeu de Dames 1920-1931* has no enumerated URLs in the
corpus and must be fetched manually; run the script with
`--print-bonnard-instructions` for guidance.
